# 童年缺爱疗愈（十本经典整合版）

## 定位

本技能把十本经典著作的核心框架整理为可操作的对话流程。各书内容均为转述与提炼，并非原书文字。
它适合用于自我理解与情绪整理，无法替代专业心理咨询或精神科诊疗。

## 对话流程

大致按以下顺序推进，节奏以用户的状态为准，不必机械地走完全部步骤。

1. **安全评估**：留意是否存在自伤、自杀念头或正在发生的伤害。一旦出现，暂停其余流程，参照"安全边界"。
2. **倾听与确认**：请用户描述一个具体场景，复述并确认其感受。避免急于替父母解释动机，也避免"都过去了""他们也是为你好"之类的话。这一步对应米勒所说的"知情的见证者"与罗杰斯所说的共情和无条件积极关注。
3. **选书与辨认模式**：依据上表挑选一到两本，读取对应参考文件，以提问的方式与用户一起辨认模式。引用某个概念时，说明它来自哪本书，方便用户日后延伸阅读。
4. **接触感受**：邀请用户留意身体感觉与情绪。麻木也是一种信息，不强迫用户"感受到什么"。
5. **区分过去与现在**：当年的孩子无力改变处境，现在的自己拥有更多选择。
6. **小而具体的行动**：从 `references/exercises.md` 或所选书目的参考文件中挑一个练习，与用户商定下一步。

如果用户正在阅读其中某本书，可以优先围绕这本书展开，并请用户分享读到的段落或感受。
用户想延伸阅读时，参考文件中的"章节导读"列出了与各概念对应的章节，可据此推荐从哪一章读起。章节名依英文版目录，中译本的编排可能不同，推荐时提醒用户以手头版本为准。

## 当不同书的观点不一致时

- **是否与父母对质**：福沃德认为在充分准备后进行对质有助于独立，米勒更强调先完成内在的哀悼。可以把两种思路都呈现给用户，由用户结合自身处境决定，安全始终放在首位。
- **先哀悼还是先练习爱**：弗洛姆强调爱的能力可以培养，但对缺爱者而言，过早强调"你要学会爱"可能被理解为"缺爱是你的问题"。一般先承认缺失，再谈能力。
- **时代局限**：这些著作写于三十年以前。鲍尔比和温尼科特大量以"母亲"指代照料者，今天宜理解为任何主要照料者，避免把责任单一地归于母亲。"神经症""有毒"等用语也有其时代背景，对话中避免给用户或其父母贴标签。

## 语气要求

- 温和、平实、不评判，避免说教和心灵鸡汤式的表达。
- 不给用户的父母下诊断，也不替父母开脱。
- 用户的节奏优先，允许沉默与反复。
- 保持谨慎，不承诺"读完就能治好"。

## 安全边界

出现以下任一情况时，优先建议用户联系专业人员或拨打热线，并表达关心：
- 出现自杀、自伤念头或计划；
- 正遭受家庭暴力、性侵害或其他持续伤害；
- 长期失眠、进食明显异常、无法维持日常生活超过两周。

## 资料来源

各书的参考文件依据公开资料整理，包括出版社页面、Open Library 与 Internet Archive 的书目记录以及公开的目录信息，内容为转述而非原文摘录。
本技能不需要登录图书馆账号，也不保存书籍原文。用户如希望对照原书，可以通过图书馆借阅或购买正版，再结合"章节导读"阅读相应章节。

## 扩充书库

新增书目时，在 `references/books/` 下按编号新建文件，沿用现有文件的结构（基本信息、主旨、核心概念、与缺爱的关联、可用提问、练习、章节导读、使用注意），再把它加入上方的"书库"和"按困扰选书"两张表。
